# কুরআন কোর্স — বিল্ড পাইপলাইন

শিশুদের (৭-১০ বছর) জন্য ২৪ সপ্তাহ / ১২০ ক্লাসের কুরআন কোর্স। বইয়ের সব
আরবির সাথে **বাংলা উচ্চারণ + আয়াতের অর্থ + শব্দে শব্দে অর্থ (বাংলা ও সহজ
ইংরেজি)** থাকে।

## পাইপলাইন

```
1. build_course_content.js   ->  course_content.js   (কনটেন্ট স্পাইন)
2. build_course_plan.js      ->  course_plan.js      (কোন ক্লাসে কোন আয়াত)
3. (পরবর্তী) build_book.js   ->  Student_Book/       (বইয়ের অধ্যায়)
```

চালানোর নিয়ম — ক্রম অনুযায়ী:

```bash
node scripts/build_course_content.js && node scripts/build_course_plan.js
```

## ফাইলগুলো

| ফাইল | কী করে |
| --- | --- |
| `bangla_translit.js` | আরবি (উসমানী) → বাংলা উচ্চারণ। **আরবি টেক্সট থেকে** চলে, ল্যাটিন ট্রান্সলিটারেশন থেকে নয় — কারণ আরবিতে শাদ্দা, সুকুন, ওয়াসলা, তানভীন সবই আছে যা ল্যাটিনে হারিয়ে যায়। দুটি মোড: `wordToBangla()` (শব্দ-ছক, পূর্ণ ই'রাব) ও `ayahToBangla()` (তেলাওয়াতের লাইন — ওয়াসল জোড়া লাগে, শেষে ওয়াকফ)। |
| `build_course_content.js` | quran.com-এর যাচাই করা ডেটা + উপরের ট্রান্সলিটারেটর মিলিয়ে প্রতিটি আয়াতের রেকর্ড বানায়। |
| `course_content.js` | **অটো-জেনারেটেড।** ৪২ প্যাসেজ / ৩০১ আয়াত / ২০৭০ শব্দ। |
| `build_course_plan.js` | সহজ→কঠিন ক্রমে ১২০ ক্লাসে আয়াত বণ্টন করে। |
| `course_plan.js` | **অটো-জেনারেটেড।** ৯৬ পাঠ-ক্লাস + ২৪ রিভিশন-ক্লাস। |

## দুটি নকশাগত সিদ্ধান্ত

**১. প্রতি সপ্তাহের ৫ম ক্লাস = রিভিশন।** নতুন কিছু নয়। স্পেসড রিপিটিশনই
মুখস্থ ধরে রাখে, তাই নতুন আয়াত ৪টি ক্লাসে ছড়ানো — ৫টিতে নয়। রিভিশন ক্লাস
সপ্তাহ `w, w-1, w-3, w-7` ফিরে দেখে।

**২. একটি ক্লাস কখনো দুই সূরায় ভাগ হয় না।** "আজ সূরা ইখলাস শেষ করব"
— এটা "ফাতিহার শেষ + ইখলাসের শুরু"-র চেয়ে অনেক ভালো পাঠ। তাই আগে প্রতিটি
প্যাসেজকে পূর্ণসংখ্যক ক্লাস দেওয়া হয়, শব্দ-বাজেট দিয়ে — যা **৮ শব্দ/ক্লাস
থেকে ৩৫ শব্দ/ক্লাস পর্যন্ত ধীরে বাড়ে**। এই র‍্যাম্পের কারণেই ১ম সপ্তাহ
হালকা (শুধু ফাতিহাই ২ ক্লাস) আর শেষে শিশু সূরা মূলক আড়াই আয়াত করে নিতে পারে।

## ডেটার উৎস ও নির্ভরযোগ্যতা

- **আরবি (উসমানী), শব্দে শব্দে বাংলা ও ইংরেজি অর্থ, আয়াতের বাংলা অনুবাদ
  (ড. আবু বকর মুহাম্মাদ যাকারিয়া)** — সবই quran.com API থেকে নেওয়া, হাতে
  লেখা নয়। কোনো আরবি বা অনুবাদ অনুমান করে বসানো হয়নি।
- **বাংলা উচ্চারণ** — `bangla_translit.js` স্বয়ংক্রিয়ভাবে তৈরি করে।
  ২০,২১৫টি শব্দে চালিয়ে দেখা হয়েছে: ১০০% পরিষ্কার আউটপুট।

### উচ্চারণের নিয়ম (ইচ্ছাকৃতভাবে একরকম)

পুরনো হাতে-লেখা ডেটায় অসামঞ্জস্য ছিল (`তাকাব্বাল` বনাম `ফাক্বীর` — একই
ق দুইভাবে; `সাবরান` বনাম `রশাদা` — তানভীন কখনো থাকে কখনো নেই)। শিশুরা
একটাই স্থির প্যাটার্ন শিখুক, তাই নিয়মগুলো এক করা হয়েছে:

- আল-প্রতিষ্ঠাসূচক সবসময় হাইফেনসহ: `আল-হামদু`, `আর-রাহমান` (শব্দ-ছকে) —
  এতে শিশু "আল" চিনতে শেখে। তেলাওয়াতের লাইনে চেনা রূপ: `আলহামদু`।
- শামসি হরফে মিলে যায়: `ٱلشَّمْس` → `আশ-শামস`
- আইন (ع) তার স্বর নেয় (আ/ই/উ); সুকুনে হলে `'` — `না'বুদু`
- শাদ্দায় যুক্তাক্ষর: `রাব্বি`, `ইন্না`
- সাধারণ যুক্তব্যঞ্জন ভাঙা হয় না (`মুসতাকীম`, `মুস্তাকীম` নয়) — ৭-১০ বছরের
  শিশু এখনো যুক্তাক্ষর শিখছে; শুধু শাদ্দাতেই যুক্তাক্ষর দরকার
- ছোট `a` ও দীর্ঘ `ā` — দুটোই `া`। বাংলা লিপিতে এদের আলাদা করা যায় না;
  মাদ্দের দৈর্ঘ্য আরবি লিপি ও তাজবীদের পাঠ থেকেই শেখানো হয়।

## এখনো বাকি

- `build_book.js` — শিশুদের জন্য ১২০টি অধ্যায় (গল্প, শানে নুযুল, মুখস্থের
  টিপস, ব্যবহারিক প্রয়োগ, খেলা) ও পূর্ণাঙ্গ শব্দসূচি।

  কাঠামোতে আছে)।
